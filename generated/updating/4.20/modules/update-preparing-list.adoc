= Removed Kubernetes APIs

{product-title} 4.20 uses Kubernetes 1.33, which does not remove any additional deprecated Kubernetes APIs beyond those already removed in prior releases. No administrator action is required for API compatibility when updating from {product-title} 4.19 to 4.20.
