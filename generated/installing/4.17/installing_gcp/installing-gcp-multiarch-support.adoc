In {product-title} {product-version}, you can install a cluster on {gcp-first} that supports multi-architecture compute nodes. A multi-architecture cluster enables you to run workloads on nodes of different architectures within the same cluster.

The multi-architecture installation feature allows clusters to include both `amd64` and `arm64` compute nodes on {gcp-short}. Control plane nodes must use a single architecture, while compute nodes can use a different architecture.

[NOTE]
====
Multi-architecture support for {gcp-short} clusters is generally available starting with {product-title} {product-version}.
====
